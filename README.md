# Online Unit Converter

## Overview
An online unit conversion application developed as part of my Bachelor's degree in Computer Systems and Technologies at the University of Ruse "Angel Kanchev".

The application allows users to convert different measurement units and manage their personal conversion history.

## Main Features
- Conversion between different measurement units
- User registration and profiles
- Conversion history
- User-oriented interface

## Main technologies Used
- C#
- Microsoft Visual Studio 2019
